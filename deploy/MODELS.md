# Моделі Agro AI

## Налаштований пул

Пул розширено з 5 до 7 різних модельних ID:

1. `gemini-3.8-flash`
2. `gemini-3.6-flash`
3. `gemini-3.5-flash-lite`
4. `gemini-3.1-flash-lite`
5. `gemini-2.5-flash`
6. `gemini-2.5-flash-lite` — додана
7. `gemini-3-flash-preview` — додана

Це список кандидатів, а не підтвердження семи доступних квот для конкретного ключа. Список звірено з офіційним каталогом/прайсингом 23.10.2026. Для Gemini 2.5 Google обмежує доступ залежно від попереднього використання проєктом; preview-моделі можуть мати суворіші ліміти. Старі неіснуючі назви та псевдоніми `latest` не додаються заради збільшення числа.

Якщо ключ працює в платному проєкті, навіть модель із free tier у каталозі може тарифікуватися за умовами цього проєкту. Програмний пул не змінює billing settings.

## Дізнатися, що бачить ключ сервера

Після оновлення та перебудови образу:

```bash
cd /opt/agro
docker compose exec app python -m scripts.list_models
```

Команда читає ключ у контейнері, викликає тільки API переліку моделей і не генерує відповіді. Ключ, URL запиту й тексти провайдерських помилок не друкуються.

У виводі:

- `listed_total`: скільки різних моделей повернув API. Сюди можуть входити моделі аудіо, відео й embeddings.
- `generate_content_total`: скільки заявляють підтримку `generateContent`. Це ще не гарантія сумісності з JSON/фото Agro AI.
- `configured_total`: скільки кандидатів налаштовано в Agro AI.
- `configured`: чи кожна модель пулу присутня в переліку й заявляє потрібний метод.
- `generate_content_models`: імена моделей із цим методом.

Перелік API не підтверджує доступну квоту або успішну генерацію. За бажанням адміністратор може явно запустити перевірку JSON-генерації:

```bash
docker compose exec app python -m scripts.list_models --probe
```

`--probe` робить по одному короткому запиту на кожну видиму модель пулу, з таймаутом 8 секунд. Використовує синтетичний текст, витрачає квоту та може мати вартість залежно від тарифу. Показує результат, клас помилки й HTTP-код; тимчасовий timeout не означає, що модель взагалі недоступна. Автоматично ця перевірка не запускається.

## Перемикання без хвилинного перебору

Наявний загальний бюджет збережено. Обмеження двох спроб для основної відповіді стосується повільних/мережевих невдач. Швидкі відмови API до однієї секунди не витрачають цей лічильник: наприклад, після кількох швидких `429` застосунок може дійти до сьомої моделі в тому самому запиті. Кожна модель пробується щонайбільше один раз у межах одного виклику `_generate`.

Дві мережеві невдачі або дві повільні помилки зупиняють цей перебір. Усі спроби також перевіряють спільний deadline. Для `429` поважаються RetryInfo та cooldown; відсутня/заборонена модель тимчасово пропускається. Глобальні помилки формату/ключа `400`/`401` зупиняють запит. Правила перевірки джерел залишилися.

## Додати інші моделі без зміни коду

У серверному `/etc/agro/app.env` можна явно задати `AGRO_EXTRA_MODELS` — модельні ID через кому. Вони додаються після основних семи; дублікати видаляються. Після зміни env потрібно пересоздати контейнер app.

Додавайте тільки перевірені Gemini-моделі для звичайного `generateContent` із підтримкою JSON і, якщо потрібно, фото. Сам факт появи в `models.list` не є такою перевіркою. Не додавайте TTS, Live, embeddings чи моделі генерації відео. Pro та інші додаткові моделі можуть потребувати платного доступу: спочатку перевірте тариф і квоту. Програма не вмикає їх автоматично.

## Чому вебчат на ноутбуці може працювати, коли Agro AI не працює

Пристрій не визначає API-квоту. Якщо порівнювати з окремим вебчатом провайдера, це інший продукт/канал доступу зі своїми умовами. Agro AI використовує серверний Gemini API-проєкт: усі користувачі застосунку витрачають квоти цього проєкту. Новий акаунт Agro AI чи новий API-ключ того самого Google-проєкту не створює окрему проєктну квоту.

Додаткові моделі можуть допомогти, якщо проблема обмежена конкретною моделлю. Вони не усувають загальну проблему мережі, ключа, billing або проєкту. Для окремого провайдера потрібна окрема інтеграція й його ключ — інші провайдери в цій зміні не додавалися.

Офіційні джерела: [моделі](https://ai.google.dev/gemini-api/docs/models), [прайсинг](https://ai.google.dev/gemini-api/docs/pricing), [ліміти](https://ai.google.dev/gemini-api/docs/rate-limits).
