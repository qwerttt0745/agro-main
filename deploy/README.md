# Oracle VM: підготовка

Шаблони розраховані на Linux із systemd, окремого користувача `agro` та каталог `/opt/agro`. На VM вони ще не встановлені й не перевірені. Для одного сімейного облікового запису SQLite достатньо: `data/chats.db` містить чати та фото, `data/auth.db` — сесії й спроби входу; Chroma — пошуковий індекс. PostgreSQL не потрібен. Запускайте один worker.

1. Перенесіть код та потрібні дані в `/opt/agro`; не переносіть macOS `.venv`, `data/auth.db`, `data/first-login.txt`. Створіть Linux venv (Python 3.11–3.13), встановіть `requirements.txt`. Сумісність пакунків з архітектурою Oracle VM слід перевірити під час установки; локальне середовище працює на macOS ARM64.
2. Створіть системного користувача `agro`. Код має читатися ним, `data/` — бути доступним для запису. Для секретів `.env` і `data/auth_credentials.json` встановіть права 600 та власника agro. Створіть `data/hf-cache/` для моделі пошуку.
3. У `.env` задайте GEMINI_API_KEY, `AGRO_COOKIE_SECURE=true`, `AGRO_PUBLIC_ORIGIN=https://ВАШ_ДОМЕН`. Не копіюйте локальне значення `AGRO_COOKIE_SECURE=false`.
4. Налаштуйте обліковий запис через `.venv/bin/python -m scripts.set_password --username tato` від імені agro. Команда попросить пароль двічі; у командному рядку пароль не передається. Зміна пароля скасовує всі попередні сесії.
5. Встановіть `agro.service` у systemd, звіривши шляхи. Встановіть Caddy з офіційного джерела, замініть домен у Caddyfile. Перевірте конфігурацію `caddy validate --config /etc/caddy/Caddyfile` перед запуском. Домен має вести на IP VM; Caddy керує HTTPS.
6. В Oracle NSG/security list та фаєрволі VM відкрийте публічно тільки 80/443; SSH обмежте своєю IP. Порт 8000 і файли БД не публікуйте. Не додавайте Caddy file_server для каталогу застосунку.
7. Після запуску перевірте: анонімний `/chats` повертає 401; `/` веде на `/login`; після входу працюють історія, фото, бібліотека; вихід скасовує доступ; cookie має Secure/HttpOnly/SameSite.

Резервна копія: `.venv/bin/python -m scripts.backup`. Поточний скрипт копіює чати/фото/профіль, але не секрети, сесії, PDF та Chroma. Окремо зберігайте книги й hash облікового запису; або відновіть пароль командою вище. На іншому шляху бажано перебудувати індекс із PDF, оскільки старі записи можуть містити абсолютні шляхи macOS. Копіювання активного Chroma не є узгодженим snapshot — зупиніть застосунок або перебудуйте індекс.

Документація HTTPS: https://caddyserver.com/docs/automatic-https
